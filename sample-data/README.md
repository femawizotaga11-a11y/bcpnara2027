# ฐานข้อมูลตัวอย่าง BCP นราธิวาส

ไฟล์ `BCP_Narathiwat_sample.xlsx` มี 8 แท็บ (KPI, Districts, Hospitals, RPH, Vulnerable, Resources, Roads, BCP)
และไฟล์ `*.csv` ของแต่ละแท็บ — ชื่อแท็บและหัวคอลัมน์ต้องตรงกับที่ Dashboard ใช้ (`index.html` → `SCHEMA`)

**ข้อมูลทั้งหมดเป็นค่าตัวอย่างเพื่อทดสอบ ไม่ใช่ข้อมูลจริง**

ใช้งาน: อัปโหลด xlsx เข้า Google Drive → เปิดด้วย Google Sheets → แชร์ "ทุกคนที่มีลิงก์ = ผู้ดู" → วาง Sheet ID ในเมนูตั้งค่า
