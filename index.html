🔗 Google Sheet & GAS Integration
① การเชื่อมต่อ
Pull = อ่านทุกแท็บจาก Sheet · Push = เขียนทับทุกแท็บที่มีข้อมูลในหน้านี้ (เฉพาะ ADMIN) · การเพิ่ม/แก้ไข/ลบในแต่ละเมนูจะ Push ทีละแถวอัตโนมัติ
② สถานะแท็บในฐานข้อมูล
สิทธิ์การเข้าถึงของแอป (Token)
บทบาทอ่านเพิ่ม/แก้ไข/ลบตั้งค่า/Push ทั้งแท็บ/แชร์ข้อมูลส่วนบุคคล
ADMIN (Full)✓✓✓เห็นครบ
EDITOR✓✓—เห็นครบ
VIEWER✓——ปิดบัง (ชื่อ/เบอร์/ที่อยู่)
กำหนดรหัสทั้ง 3 ระดับในไฟล์ Code.gs (ค่า TOKENS) · ตัวแอปตรวจสิทธิ์จริงที่เซิร์ฟเวอร์ ไม่ใช่แค่ซ่อนปุ่ม
ปลดล็อกการแชร์ไฟล์ Google Sheet (ต้องใช้ ADMIN)
⚠ ชีตนี้มีข้อมูลส่วนบุคคลของกลุ่มเปราะบาง (ชื่อ ที่อยู่ เบอร์โทร) แนะนำ "ส่วนตัว" แล้วให้แอปอ่าน/เขียนผ่าน Web App + Token เท่านั้น เปิด Full เฉพาะกรณีจำเป็นและต้องรับผิดชอบความเสี่ยงเอง
ขั้นตอนปลดล็อกสิทธิ์ Web App
1Apps Script → Deploy → New deployment → ประเภท Web app
2Execute as: Me · Who has access: Anyone (การป้องกันจริงอยู่ที่ Token)
3กด Authorize อนุญาต Sheets/Drive แล้วคัดลอก URL /exec มาวางในแท็บ "เชื่อมต่อ"
4กด "ตรวจสอบการเชื่อมต่อ" ต้องเห็นบทบาท ADMIN/EDITOR จึงจะ CRUD ได้
Code.gs ฉบับสมบูรณ์ — สร้างฐานข้อมูลทั้ง 17 แท็บ ตรวจสอบข้อมูลฝั่งเซิร์ฟเวอร์ CRUD ทีละแถว บันทึกประวัติ (Log) ปิดบังข้อมูลส่วนบุคคลสำหรับ Viewer และจัดการสิทธิ์แชร์
กำลังโหลด…
1เปิด Google Sheet → Extensions → Apps Script → วางโค้ดทั้งหมดแทนของเดิม
2ตรวจ TOKENS ด้านบน (ADMIN = EDITOR = admin; VIEWER ต้องตั้งรหัสเองก่อนจึงจะใช้ได้) แล้วเลือกฟังก์ชัน setupDatabase → Run → อนุญาตสิทธิ์
3Deploy เป็น Web app (ดูแท็บ "ปลดล็อกสิทธิ์") แล้วนำ URL + Token กลับมาใส่
⚙ ตั้งค่าการแสดงผลและเกณฑ์แจ้งเตือน
